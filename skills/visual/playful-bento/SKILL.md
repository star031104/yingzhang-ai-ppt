# 活力便当 · 创意展示

仅影响视觉表达：使用大小不等但对齐严谨的模块组成便当网格，以一块深色主卡统领层级。明快色彩只用于重点，避免每块颜色都不同。每页控制三到五个模块，适合轻数据、案例、功能卖点和作品展示。

## 版式语法

窄边距与小栏距形成拼贴感，点阵与圆形装饰保持活力，图标使用圆角方形容器，图表柱体使用大圆角并去掉网格。具体参数见 tokens.json 中的 grid、typeScale、density、decoration、titleStyle、chartStyle、iconStyle 与 forbidden。
