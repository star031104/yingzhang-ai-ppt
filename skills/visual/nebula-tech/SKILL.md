# 星云科技 · 产品发布

仅影响视觉表达：用深色封面、冷色强调和清晰的技术结构图形成舞台感。正文保持浅色底以保证长时间阅读，关键概念用高对比面板呈现。拒绝霓虹堆叠与无意义光效，数字、流程和架构必须保持可编辑。

## 版式语法

深色舞台搭配径向光晕、圆形装饰与点阵；标题紧凑有力，图标使用圆形描边容器，图表柱体保留小圆角。具体参数见 tokens.json 中的 grid、typeScale、density、decoration、titleStyle、chartStyle、iconStyle 与 forbidden。
