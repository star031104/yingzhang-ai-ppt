# 瑞士网格 · 专业简报

仅影响视觉表达：使用明确的十二栏网格、左对齐标题、克制色彩、低圆角和高信息层级。每页保留一个主视觉锚点，避免装饰性渐变、无意义图标和平均分栏。图表优先直接标注，正文控制为两到四组信息。

## 版式语法

十二栏网格与细栏线定位内容；标题左对齐、字距收紧，标题上方红色短横为唯一装饰；禁止渐变、阴影、光晕和大圆角，图表网格只保留横线。具体参数见 tokens.json 中的 grid、typeScale、density、decoration、titleStyle、chartStyle、iconStyle 与 forbidden。
