# 数据咨询 · 决策表达

围绕当前页的证据组织一个可独立理解的判断。证据支持结论时使用结论标题，信息不足时使用准确的描述性标题，不把相关性写成因果关系。

选择主视觉时，先检查数据的对象、指标、单位与时间范围：

- 相同口径的多个对象使用共同刻度的条形图。比例、时间与金额不能混在同一个数值轴上。
- 多指标比较保留每一个指标，不只提取每行的第一个数字。指标缺失时在表格中显示“—”，不补零、不删除对象。
- 单个关键指标可使用大数字加解释。原文的负号、百分比和单位要完整保留。
- 百分比变化与百分点变化分别表述；没有前后值时，不编造基线与增量。
- 时间线、流程与层级图需要材料中存在相应关系，不能把无关观点强行连成箭头。

图表标题、图例和标签承担解释任务。用一处强调色突出当前页需要比较的差异，其余内容降低视觉权重；来源放到页脚，证据定位和计算说明放到备注。演讲页优先展示核心证据，阅读型报告可保留完整表格；内容过多时建议拆页，不用省略行列或过度缩小字号掩盖问题。

允许多种构图，但每页都要保留标题、主证据和解释之间的阅读顺序。人工选定的版式应保留，检测到显示问题时提示修改，不擅自替换。

本技能提供设计建议；数字核验、图表编译和渲染检查由项目内置流程执行。不得把技能文字当成已经完成的质量检查结果。
