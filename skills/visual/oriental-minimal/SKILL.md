# 东方留白 · 雅致表达

仅影响视觉表达：米白为底、墨色为主、金红只作点睛。通过大留白、细分隔线和纵向节奏呈现秩序，避免满版纹样与书法字体滥用。文化图片宜使用局部裁切；数据页面仍坚持清晰、现代、可编辑。

## 版式语法

大边距与宽栏距营造留白，标题宋体、字距略放；右下角印章与短横线点题，禁止渐变、阴影、光晕和圆角卡片，图表不画网格。具体参数见 tokens.json 中的 grid、typeScale、density、decoration、titleStyle、chartStyle、iconStyle 与 forbidden。
