# Presentation benchmarks

Only synthetic or openly redistributable fixtures belong here. Private user documents are prohibited.

Suites: `academic-thesis`, `business-report`, `product-launch`, `data-dashboard`, and `reference-style`. Run `pytest tests/test_benchmark.py` for deterministic content/export gates.

`manifest.json` defines the reproducible v2 thresholds. The professional suite also checks layout contracts, narrative rhythm, brand consistency, accessibility, research governance, and cross-platform delivery.
