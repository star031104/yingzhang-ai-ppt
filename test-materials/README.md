# 测试材料使用说明

1. 在“模型配置”填写兼容 OpenAI API 的地址和密钥，点击“测试连接并获取模型”，选择模型后保存。
2. 在“新建演示”上传 `01_毕业答辩测试材料.md`，主题填写测试 Prompt 中的“毕业答辩”内容，选择 12 页。
3. 再上传 `02_季度经营数据.csv` 测试数据型经营汇报。
4. 生成完成后分别下载 HTML、PPTX、PDF，检查数字、来源、中文排版和可编辑性。
5. 在“技能库”粘贴包含 `skill.json` 的公开 GitHub/GitLab 项目链接，验证下载、扫描、安装与卸载。
6. 不上传任何文件，使用测试 Prompt 中的“无文件创作”主题，选择“数据咨询 · 决策表达”，验证主题直创、项目保存、微调和三种格式导出。

## 推荐的小模型专项测试

使用 `小模型规则编排测试` 文件夹内的四份材料和 `测试Prompt与验收标准.md`。配置 Qwen3-8B 后创建 18 页本科答辩，项目工作区应显示“10B 以内·强约束模式”、5 个受控批次，并按验收标准检查真实数据图、可编辑结构图、来源和重复内容。
