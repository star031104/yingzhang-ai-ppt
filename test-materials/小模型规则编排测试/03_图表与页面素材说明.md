# 图表与页面素材说明

## 必须制作的可编辑图表

1. 应用二分类方案对比：比较关键词规则、自由生成小模型和证据契约的 Accuracy 与 F1。
2. RAG 检索效果：比较无任务约束 RAG 与证据契约的 Hit@5 和 MRR。
3. 报告质量：比较两种方案的证据支撑率与结构完整性，并单独说明平均耗时的代价。

## 必须制作的可编辑语义图

1. 总体技术路线：材料输入 → 证据索引 → 任务合同 → 小模型微任务 → 事实复核 → 可追溯报告。
2. 五层系统架构：材料层、证据层、编排层、模型层、交付层。
3. 权限一致性分析：隐私政策声明、权限清单、业务场景三方对齐，输出未声明、过度申请和用途不一致。

## 图片规则

封面可以使用抽象的“文档证据网络汇聚成清晰路径”主题配图。实验结果页、系统架构页和流程页不得使用生图模型代替真实图表或可编辑结构图。所有图片必须无水印，正文中引用的材料图必须保留来源。
